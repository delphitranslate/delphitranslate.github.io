Safe first run

A safe first project workflow.

  1. 1Read the V2 User and Setup Wizard guides. Prepare a version-controlled test copy of the target application before integration.
  2. 2Keep the software together. Use the Studio, component packages, and source from one matching build.
  3. 3Identify the original app language. Check the text saved in its Delphi forms and resources rather than assuming English.
  4. 4Translate and review. Use the Wizard for a first target; use Maintenance Studio to add several languages to a saved project.
  5. 5Validate before optional export. Inspect every chosen language, then deploy only the approved packs and test them in the actual application.
