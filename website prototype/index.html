Translation that understands UI

“Play” should not become a theatrical performance.

Short interface words are deceptively difficult. The Studio records where text appears, what the control does, and which semantic concept applies. Approved project terminology remains authoritative over provider output.

  • Context-aware terms for actions such as Close, Play, Schedule, Activate, and Enable
  • Translation provenance and confidence reporting
  • Developer-approved project glossary and reusable translation memory
  • Suspicious or application-data text withheld from automatic translation

Designed around valuable source code

Your application remains designer-owned.

The recommended component workflow does not rewrite Pascal, DPR, DFM, or FMX source. Integration uses a generated component kit, a verified backup, and a small marked DPROJ configuration block.
