# Unpublished Website Prototypes

These two static pages are local design prototypes only:

- `index.html` — product overview and announcement page
- `downloads.html` — planned source, binary, and documentation download center

They have not been published or pushed to GitHub. Open `index.html` locally to review the prototype.

The pages identify the project as a limited beta under the Apache License 2.0. The compiled download remains disabled, and the documentation is presented as the current beta documentation set.

The pages include the required local `assets/translation-selector.js` integration and GTranslate floating widget. Product names are protected with `notranslate` and `translate="no"` where appropriate.
